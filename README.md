## Описание
Интеграция котлов Navien через NaviLink (вода, температура, режимы).
### Возможности
- Числовые настройки и параметры
- Сенсоры и мониторинг состояния
- Переключатели и вкл/выкл устройства
- Управление водонагревателем
### Установка
1. Скопируйте папку `custom_components/navien/` в каталог `custom_components/` конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Navien**.
> Установка через HACS: добавьте репозиторий `https://github.com/bezuglyy/navien` как Custom repository (категория Integration).

## Description
Navien boiler integration via NaviLink (water, temperature, modes).
### Features
- Number settings and parameters
- Sensors and state monitoring
- Switches and on/off controls
- Water heater control
### Installation
1. Copy the `custom_components/navien/` folder into the `custom_components/` directory of your Home Assistant configuration.
2. Restart Home Assistant.
3. Settings → Devices & Services → Add Integration → **Navien**.
> HACS: add `https://github.com/bezuglyy/navien` as a Custom repository (category Integration).
